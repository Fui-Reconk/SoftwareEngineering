# TACES 前端设计

这份文档定六页前端长什么样、各自回答什么问题，以及为什么这么定。实现计划另存 `project/docs/plans/`。

## 1. 现状

`project/demo/` 里已经有一页教师看板，是独立静态页：数字在 `assets/data.js` 里自造，没有一处 JS 调接口。
它证明了两件事：版式规则立得住，松绿这套 token 能用。它还没证明的是能接上后端。

`presentation/` 现在只有 `auth.py` 和 `health.py` 两个路由，`templates/` 三个目录是空的，
`app.py` 建 Flask 时显式关掉了静态与模板（`static_folder=None, template_folder=None`）。

## 2. 意图

六个页面、一套视觉、每页单独可验收。数字经一层适配代码取，后端接口到位后只换那一层。

非目标：不引前端框架、构建工具、CSS 框架、图标库；不改 `business/` 和 `data/`；不改 SRS 与正稿。

反目标，做到也算失败：六页各写各自的颜色和间距；假数据散落在模板里；为了过闸去加 `--allow`；
为了好看牺牲「学生三步交完」。

## 3. 约束

- 视觉规则不重述，见 `references/app-screens.md`。本次构图由 skill 发出：
  - 整体风格 `framed-sheet`（seed 2001092293）：染色 L 形框，白纸内嵌 8px、1px 边、16px 圆角、无阴影。
  - 管理员参数页用库里的 `settings` 构图（seed 1139635691）：左 450 标签列加右面板，节间 32px。
  - 审计日志页库里没有现成构图（`list` 那条无模式），按 `references/app-screens.md` §7 的表格规则自己组。
  - `detail` 构图用不上，这六页没有对象详情页。
- 色调松绿：纸 `#edf1ee`、数据 `#1f6b4e`。token 只有一份，在 `static/css/app.css` 的 `:root`。
- 字体 Noto Sans SC（本机已装，一个 family 吃中英与数字），不引外部字体。
- `project/demo/` 保留为版式参照，不删，也不再跟着一起改。六页以服务端渲染为准，
  「双击打开静态页」不再是新页面的验收标准。
- 所有路径相对。

## 4. 定下的判断

每一条都是这次设计里必须现在定、否则计划会写歪的地方。写明代价，猜错时好回退。

1. **数据经模板骨架进页面。** 模板出标题、区块标题和固定文案，JS 只把数字填进 `data-slot` 槽位。
   不用 demo 那种「JS 画整页」。代价：标记多一层槽位约定。换来 pytest 能断言页面内容，关掉 JS 还剩骨架。
2. **两种壳。** 登录页与学生两页用居中单列（一条极简顶栏只放产品名）；教师看板与管理员两页用侧栏壳。
   两套共用同一份 token 与纸面结构。代价：`base.html` 要一个「是否带侧栏」的开关。
3. **拒绝走 `200` 加状态字段，不走错误响应。** 统计接口在拒绝时返回
   `{ state: "unpublished", reason: "below_threshold", sample, threshold, shortfall }`。
   理由：拒绝屏要带四个可核对的数，错误体 `{code, message}` 装不下。
4. **「预算耗尽」不是一种拒绝态。** 教师始终看得到数据：预算用完后看到的是最后一次发布的结果，
   页脚写一行「这是 2026-06-30 发布的版本，预算已用完，不会再更新」。
   理由：预算限制的是「能不能发新的」，不是「能不能看旧的」，看旧的不花预算。
   代价：`state` 只需要 `published` 与 `unpublished` 两种。
5. **评价码随评分一起 POST，不放 URL。** 放 URL 会进浏览器历史和访问日志，等于把一次性凭证写进日志。
   无码直接打开 `/student/evaluate` 时回 `/student`。代价：评分页要一个前端守卫。
6. **ε 按发布扣费，配置页那一行是「每次发布 ε」，现值 `0.10`。** 与 `BACKEND.md`、用例描述一致，
   也正好消掉重复查看重复扣费的问题。看板区间仍是 ±0.39。代价：SRS FR6 的「按查询扣费」要在交付文档里说明口径变更。
7. **`ε_total` 每门课一份，ε 与 k 是全局策略。** 依据：`budget_ledger` 本身就是 `course_id` 唯一，一课一行。
   代价：参数页三行里 `ε_total` 那行是「每门课」而不是「全局」。
8. **区间、差值、能否比较由后端算好放进响应。** 响应带 `interval`、`spread`、`distinguishable`。
   前端不重算差分隐私。代价：统计接口要带这三个字段。
9. **参数页的允许范围与单位由接口返回**（`ranges: { epsilon: {min, max}, … }`），页面不写死数字。
   理由：`BACKEND.md` 明确说本片不设定未验收的隐私默认值，页面发明范围会与第 5 片打架。
10. **审计页管理员与审计员共用，只读。** 接口返回已翻译的用户名、中文动作名、`Asia/Shanghai` 时间；
    课程筛选的选项由审计接口自己给，因为审计员只有 `audit:read`，拿不到 `/api/courses`。
    一次 50 条加「加载更多」。代价：审计接口要做一层动作名映射。
11. **错误页按路径前缀分流。** `/api` 前缀走 JSON，其余渲染 `error.html`。
    代价：要改一条已通过的集成测试（`test_http.py` 里断言 `/not-a-route` 返回 JSON）和 `BACKEND.md` 一行。
12. **补一条 `/` 按角色跳转。** 教师进自己第一门课的看板，管理员进参数页，审计员进审计页。
    侧栏含课程列表与退出。代价：多一条路由和一次课程列表请求。
13. **契约文件由前端编写。** `API_CONTRACT.md` 标「前端预留」，字段以 SRS 第 6 章与现有 auth 契约为准；
    后端实现时以它为准，改了就在这份文件里登记差异。

## 5. 六页

每页只回答一个问题。区块清单就是页面上真正存在的东西，没列进去的就是不做。

### 5.1 登录 `/login`

问题：我该用哪个身份进来。

区块：产品标与名称、`h1` 登录、用户名、密码、登录按钮、一行「学生不用登录，凭评价码进入评教」。

状态：凭证错误一句「用户名或密码不对」；15 分钟内失败 5 次后「尝试次数过多，稍后再来」；提交中按钮禁用。

成功后按角色去 `/`（见判断 12）。

不做：找回密码、注册、记住我。

### 5.2 教师看板 `/teacher/<course_id>`

问题：这门课学生到底怎么评的，这个数能信几分。

区块：标题行（课程、学期、选课与有效份数、发布状态、导出）、
主卡（左：联合均分与噪声区间、一句结论、三个维度的区间对比；右：评分分布，柱可悬停出条数与占比）、
开放题高频词（十二项，三列各四条）、页脚记录行。

两种状态：
- `published`：上面这套。
- `unpublished`：整页换成拒绝态，左说为什么不出数，右四行可核对的数（门槛 k、当前 n、缺口、本次扣费）。

预算用完时页面仍是 `published`，只在页脚加一行「预算已用完，这份不会再更新」，不换版式。
看板不显示 ε 账本。

不做：预算账本、口径推导。这两样属于文档和管理员页。

### 5.3 学生评价码校验 `/student`

问题：这串码还能不能用。

区块：`h1` 进入评教、一句说明、评价码输入、继续按钮、一行「评价码一次性，提交后作废」。

状态：三种失败各一句——「已经用过了」「没有这个码」「窗口已关闭」，就地显示在输入框下方。

不做：学号登录、查询历史。

### 5.4 学生评分 `/student/evaluate`

问题：三个维度怎么打分，写完怎么交。

区块：课程名与授课教师、一句匿名说明、三个维度各一行（每行五个选项横排，单选不用滑块，键盘可达）、
开放题输入框带 500 字计数、提交按钮。

状态：三项没选满时按钮禁用并写明还差哪个维度；超字数就地提示；提交成功整页换成回执，
写明「已提交，不能再改」；提交时码已失效则回 `/student` 并说明原因。

不做：分页、草稿保存、进度条。

### 5.5 管理员参数 `/admin/config`

问题：每次发布 ε、门槛 k、每门课的预算总量现在是多少，改完什么时候生效。

区块：`h1` 隐私参数、三行（每次发布 ε、出数门槛 k、每门课预算总量），每行带现值、允许范围、
一句后果说明；一个保存；一行「改完不影响已发布的结果，新发布按新参数算」。

`ε_total` 那行标明「每门课」。范围与单位由接口给（判断 9）。

状态：非法值就地拒绝并说明范围；保存成功后原地给一句「已生效」，不弹窗。

不做：账号管理（第 2a 片已有接口，页面另说）。

### 5.6 审计日志 `/admin/audit`

问题：谁在什么时候查了什么。

区块：`h1` 查询留痕、筛选（时间范围、课程）、表格（时间、操作者、动作、对象、消耗 ε）、
「加载更多」、底部一行「只增不改，没有删除入口」。

状态：无结果时保留表头，表格区给一句「这段时间没有查询记录」。

管理员与审计员都能进，只读（判断 10）。

不做：导出、删除、编辑。

## 6. 接口预留

三层，只有中间那层会在接后端时被替换：

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 契约 | `project/docs/API_CONTRACT.md` | 前端依赖的方法、路径、请求体、响应字段、错误码。后端没实现的标「待实现」 |
| 适配层 | `static/js/api.js` | 页面唯一的取数出口。一个 `USE_MOCK` 常量在假数据与 `fetch` 之间切换；写操作带 `X-CSRF-Token` |
| 假数据 | `static/js/mock.js` | 按契约形状写死，数值与看板 demo 一致 |

`USE_MOCK` 默认 `true`。起服务后页面能看；改成 `false` 之后六页的取数路径必须全部指向契约里的接口。

## 7. 每页算做完的标准

1. `lint.mjs --app` 0 FAIL / 0 WARN。
2. 关键页（教师看板、学生评分）另跑 `inspect.mjs --app`，1440 / 768 / 390 三个宽度 0 FAIL / 0 WARN，截图逐张看过。
   其余四页过 lint 加桌面目视，手机宽度在收尾任务里统一补。
3. 页面数字都经 `api.js` 取，模板里不出现写死的成绩、人数、词频。
4. 有 `h1`、键盘可达、有关键错误态。
5. 页头页脚只来自一份模板。

## 8. 留给实现者

- 每页槽位命名与 JS 填数函数的切分方式。
- 学生评分页五个选项的具体控件形制（radio 分组与焦点顺序）。
- 表格列宽与数字对齐的具体取值。
- 登录态与权限在页面这一侧怎么落地（`/api/auth/me` 返回 401 时跳登录并记住原地址）。
