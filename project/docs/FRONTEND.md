# TACES 前端实现说明

更新日期：2026-10-28。本文描述当前已合入主分支的 Flask 页面；字段定义见 [API_CONTRACT.md](API_CONTRACT.md)。

## 当前状态

登录、本人修改密码、教师看板、学生验码、学生评分、管理员账号管理、管理员课程管理、管理员隐私配置、审计日志等功能页面及入口页均已实现。Flask 已启用模板与静态资源，页面路由位于 `src/taces/presentation/routes/pages.py`（以下源码路径均以 `project/` 为基准）。

**当前 `static/js/api.js` 中的 `USE_MOCK=false`。** 页面默认读取真实API，数据生成器安装的账号可直接登录。Mock文件仅用于手动启用的静态调试，不能将其中的模拟口令用于真实账号。真实登录、Cookie会话与四个启用演示账号的角色跳转已增加回归；其他页面边缘交互继续按实际验证记录验收。

教师看板可下载当前已发布快照的 CSV/PDF，也可输入已知的历史发布编号下载旧快照；未发布时当前结果的导出按钮不可用。侧栏“导出快照”提供独立入口，可选择课程后直接下载最近一次或指定编号的快照，不会先请求统计发布接口。导出复用已发布数据，不重新发布或消耗隐私预算。静态 Mock 模式不提供文件导出。

## 页面入口

| 页面 | 路径 | 实现 |
| --- | --- | --- |
| 员工工作区分流 | `/workspace` | entry.html + pages/entry.js，浏览器读取会话并按角色跳转；无课程时可重新检查、修改密码或退出 |
| 登录 | `/login` | auth/login.html + pages/login.js |
| 本人修改密码 | `/account/password` | auth/password.html + pages/password.js，成功后提示重新登录 |
| 教师看板 | `/teacher/<course_id>` | teacher/board.html + pages/board.js |
| 教师快照导出 | `/teacher/exports/history` | teacher/exports.html + pages/exports.js，不请求统计发布接口 |
| 学生验码 | `/`、`/student` | student/code.html + pages/code.js，主按钮下提供教职工登录入口 |
| 学生评分 | `/student/evaluate` | student/evaluate.html + pages/evaluate.js，提交成功后可手动返回首页，或等待5秒自动返回 |
| 账号管理 | `/admin/accounts` | admin/accounts.html + pages/accounts.js，管理员创建和维护员工账号 |
| 课程管理 | `/admin/courses` | admin/courses.html + pages/courses.js，管理员维护课程、评价设置与发码 |
| 隐私配置 | `/admin/config` | admin/config.html + pages/config.js |
| 审计日志 | `/admin/audit` | admin/audit.html + pages/audit.js |

模板位于 `src/taces/presentation/templates/`，JS位于 `src/taces/presentation/static/js/`。员工页面共用 `base.html` 与 `shell.js`：会话守卫、CSRF元信息、课程列表、账号、退出和移动侧栏。会话Cookie只在 `/api` 路径发送，页面路由不从Cookie判断角色，员工登录后的工作区分流在浏览器完成。

## 布局与取数

- Jinja 提供标题、固定文案与内容槽位；页面JS填充数据和绘制图表。不引入前端框架或构建工具。
- 公共token位于 `static/css/app.css` 的 `:root`，纸色 `#edf1ee`、数据色 `#059490`；登录和学生页面背景为 `#00707c`。字体优先本机 Noto Sans SC，并配置系统字体回退。
- 登录和学生验码页在宽屏使用表单与评教图形双栏，手机使用单列表单；学生评分页保持单列，教师、账号管理、课程管理、配置、审计使用侧栏壳。登录、工作区分流和学生页面底部显示 TACES 版权标识。
- 页面统一通过 `window.API` 取数。`api.js` 的Mock分支与fetch分支返回接口的data部分，错误转换为APIError。
- fetch分支携带同源Cookie与 `X-TACES-Request: 1`；员工写请求有CSRF值时发送 `X-CSRF-Token`。学生凭评价码提交，不要求员工会话或CSRF。
- 管理员导航为“账号管理 / 课程管理 / 隐私参数 / 查询留痕”，可随时返回配置；审计员只显示“查询留痕”。这两种角色的侧栏不请求课程列表，也不显示教师结果入口。教师侧栏提供独立的“导出快照”入口，并请求和显示本人课程，空列表与加载失败分别提示。审计筛选项直接由 `/api/admin/audit` 返回。
- 侧栏沿用登录页的青绿色系，底部账号和退出位于浅色区域。品牌、可滚动中部、账号退出分为三行，只有中部导航滚动。宽屏侧栏常驻；860px及以下通过顶部菜单打开抽屉，关闭时隐藏内部焦点项，打开状态切回宽屏会清除遮罩。
- `project/demo/` 是正式页面实现前的独立静态原型，只在本地保留，正式运行与验收均不依赖该目录。历史实施计划也只本地保存。

## 业务展示规则

教师看板读取已发布统计或未发布状态。噪声区间、维度差距与可区分性由后端计算；前端不重新实现隐私计算。页面按照返回的维度数量展示结果，不假设课程均使用默认三个维度。

发布成功显示均分、区间、维度、分布与受限词频，不展示开放题原文或预算账本。`enrolled` 是快照发布时的评价码发行数量，页面显示为“已发评价码”，不能将其当成学生名册人数。未发布屏按reason分别显示样本不足或预算耗尽，不把已达样本门槛的预算拒绝引导为继续补交评价。真实distribution按每份评价的均分分桶，页面计数与图表单位均为“份”。

已有快照时，预算不足只限制新发布，旧结果可以继续读取；`budgetExhausted=true` 时页面提示当前预算不足以再次发布；管理员调整预算后，满足发布条件时仍可产生新快照。默认每次发布ε=0.1，实际噪声区间由后端根据样本与维度计算，不能把Mock中的固定区间当成真实默认值。

学生评价码经POST校验，不放URL。评分页从前端会话状态取课程与评价码，无该状态则返回验码页；评分与评语在评价库中属于同一份匿名评价，教师页面与导出不展示评语原文。所有维度选满后才允许提交，开放题最多500字符；成功后显示回执，已用码或过期码返回入口处理。

账号管理页支持分页查看、新建、启停、角色修改及密码重置；修改后目标账号需要重新登录。所有教职工也可从账号区修改本人密码，须提供当前密码，成功后撤销本人全部会话。后端会阻止停用或降权最后一个启用的管理员，以及直接更改仍有关联课程的教师角色。

课程管理页支持创建课程、修改名称与学期、分配或转移任课教师、设置截止时间及发放评价码；教师选项只包含已启用教师，并会读取全部账号分页。新建课程默认评价窗口为7天、使用三个默认维度；创建时可选1–10个名称唯一、权重为正且合计为1的自定义维度。已有课程不支持修改维度。发码支持1–1000个及可选的提前过期时间；明文只在发放响应中出现一次，页面提供复制与文本下载，并在离开前提醒保存。延长课程窗口不会延长已发行码的有效期。

隐私配置页从接口读取values/ranges/units，提交顶层epsilon/k/epsilonTotal。ε与k是全局策略，epsilonTotal是每门课预算上限。审计页只读，提供时间/课程过滤与分页，不提供编辑或删除。

## 运行与验证

以 `project/` 为当前目录：

```bash
python run.py
python -m pytest -q tests/pages tests/system/test_entrypoint.py
node --test tests/js/*.test.cjs
```

页面测试检查路由、模板骨架与关键控件；Node回归执行真实配置页JS，并分别用真实后端与Mock验证请求保存回读。登录回归另外执行实际api.js、login.js和entry.js，对接临时库的真实HTTP服务，检查启用账号、错误密码、旧Mock口令及停用账号。账号管理JS回归覆盖创建、编辑、本人变更后的重新登录提示、分页和错误重试；课程与入口JS回归覆盖教师分配、截止时间、维度、一次性发码、账号分页、错误重试和无课程状态；改密与导出JS回归覆盖成功、错误及发布编号，后端鉴权集成测试另验证会话撤销。学生评分回归检查提交成功后5秒返回，以及普通失败和失效码处理。shell回归覆盖三角色导航、当前页标记、空课程、失败/过期会话及移动抽屉切回桌面。侧栏已在1440/768/390宽度、长课程列表与390×320短屏上测量头尾固定和中部独立滚动；这不等同于全部页面的全面视觉验收。

已通过真实浏览器验证生成数据副本上的教师、管理员与审计员登录和相应页面，以及预算耗尽拒绝；全部启用账号的Cookie会话/角色跳转另有真实HTTP回归。学生验码、评分、提交及手动或自动返回已在临时合成库中通过浏览器验证；课程设置、发码和教师当前快照导出也已使用临时合成库通过浏览器验证；历史快照导出由后端集成测试与前端回归覆盖。登录故障修复将默认取数切换至真实API，没有修改数据库密码或降低密码散列强度。
